10  Writing applets with an AI assistant

A single self-contained HTML file with a few sliders and a plot is exactly the kind of thing Claude or ChatGPT produces well in one go. This is where the effort really collapses: the statistics applets in the BMS book are of this kind, and each took minutes rather than days.

The catch is in the title of this chapter’s key section: if you are careful.

10.1 Constrain the request

The constraints below are what separate a file that still works in five years from one that mysteriously stops working in March.

  • One single .html file. All CSS and JavaScript inline. No npm, no build step, no separate files. If the answer needs installing, it is the wrong answer.
  • No external libraries, no CDN links. Plain JavaScript and a <canvas> element cover almost everything a statistics or modelling applet needs. A library pulled from a CDN means the applet dies whenever that CDN does, or whenever a student has no connection.
  • Say the width is fluid and give the height. “It will be embedded in an iframe at width: 100%, height: 620px. Use a responsive layout; nothing may overflow at that height.”
  • Ask it to set the background colour explicitly, and to handle light and dark colour schemes. Otherwise the applet inherits nothing and looks unfinished.
  • Ask it to state the formula it implemented in a comment at the top of the file, in mathematical notation. That one line is what makes the file checkable.
CautionA prompt you can paste

Write me a small interactive teaching applet as one single, self-contained HTML file.

Topic: [what it should show — e.g. “the sampling distribution of the mean: the student sets the population SD and the sample size n, draws many samples, and sees the distribution of sample means beside the population distribution”]

Controls: [which sliders or inputs, and their ranges]

Language of all labels: [English / Dutch]

Hard requirements:

  • One file. All CSS and JavaScript inline. No npm, no build step.
  • No external libraries and no CDN links. Plain JavaScript and <canvas> for plotting. It must work with no internet connection.
  • It will be embedded in an iframe at width: 100%, height: [N]px. Use a responsive layout; nothing may overflow or scroll inside the frame.
  • Set the background colour explicitly on body, and support both light and dark via prefers-color-scheme.
  • Readable at phone width.
  • Put a comment at the very top stating exactly which formula or algorithm you implemented, in mathematical notation.
  • Keep it simple and readable — I need to be able to check it.

Start with the simplest version that works. I will ask for additions afterwards.

10.2 Then check it

ImportantAn applet that looks convincing and computes the wrong thing is worse than no applet

Students trust it more than they trust you. Five minutes, every time.

  1. Read the formula comment at the top of the file. Is it the formula you actually teach, in your notation?
  2. Open the file directly in a browser by double-clicking it, before any iframe is involved. It must work standalone.
  3. Check three numbers against R. Pick inputs you can compute yourself, including one extreme case. For a p-value applet: does it agree with 2 * pt(-abs(t), df = n - 1)?
  4. Push every slider to both ends. \(n = 1\), \(\alpha = 0\), \(r\) at maximum. AI-written applets are reliably right in the middle of the range and reliably produce NaN, an empty plot or a freeze at the edges.
  5. Check the language and notation match the rest of your book. Assistants drift into English and into whatever notation is commonest online.
  6. Narrow the browser window to phone width.
  7. Render the book and open the real chapter page, not just the file.
NoteThis is not hypothetical

The applet embedded in Chapter 8 was written this way and then run through the list above. Steps 3 and 4 caught a real bug: at very low growth rates it labelled a population that was still slowly growing as “oscillating”, because the classifier only looked at the spread of the last few values and never asked whether they were still rising. Correct everywhere in the middle of the range, wrong at the edge — exactly the failure mode step 4 exists to catch.

10.3 The rhythm that works

Ask for the smallest version first — one slider, one plot — and check it. Then ask for one addition at a time.

A 500-line applet produced in a single shot is genuinely hard to verify. The same applet grown over four steps is easy, because you checked each step while it was still small.

10.4 If you do accept a CDN link

Sometimes a plotting library is worth it. The BMS applets use Chart.js this way. If you go there:

  • Pin the exact version — chart.js@4.4.0, never chart.js@latest.
  • Know that you have made your book depend on somebody else’s server, and that the applet will not work offline or in an exported copy.
  • Note it somewhere, so whoever inherits the book knows why it broke.
